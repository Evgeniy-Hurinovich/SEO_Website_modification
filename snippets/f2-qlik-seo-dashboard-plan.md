## Как устроить данные → Qlik (рекомендация)

**Не так:** git-логика → «тестовые платформы» Lighthouse/PSI как стенды → личный Excel на личном GitHub → Qlik как-нибудь это увидит.  
Lighthouse — **измеритель URL**, не стенд. Официальный KPI — только **https://a2c.by/**. Стенд — лишь проверка до выкладки.

**Так:**

```
Пн 09:00  seo_weekly_monitor.py
          Lighthouse 12.2.1 mobile+desktop  →  a2c.by
          live probe (canonical / robots / sitemap)
          опционально: GSC / Метрика
                ↓
          metrics/history.jsonl
          metrics/weekly_snapshot.csv   ← стабильная схема
                ↓
          папка, которую Qlik уже умеет читать
          (шара / Bitrix.Disk / drop Qlik)
                ↓
          Qlik Sense  reload Пн 10:00
          лист 1: 5 KPI + тренд
          лист 2: сырая таблица
```

Каркас сборщика: `scripts/seo_weekly_monitor.py` + сид `metrics/history.jsonl` (11.08, 20.08).  
Не хватает только **экспорта CSV** и **места выкладки** для Qlik.

### Схема CSV (контракт)

Одна строка = одна метрика за дату. Не «широкая» простыня, которая ломается при новой колонке.

| date | contour | device | metric | value | unit | source | url |
|------|---------|--------|--------|-------|------|--------|-----|
| 2026-08-20 | lab | mobile | perf | 62 | score | lighthouse-12.2.1 | https://a2c.by/ |
| 2026-08-20 | lab | mobile | lcp_ms | 5745 | ms | lighthouse-12.2.1 | https://a2c.by/ |
| 2026-08-20 | live | — | canonical_ok | 0 | bool | html-probe | https://a2c.by/ |

Qlik тогда сам строит «широкую» витрину. Ручной ввод GSC — те же колонки, `contour=gsc`.

### Куда класть файл (по приоритету)

1. Папка на файловом ресурсе, к которому у Qlik уже есть Folder Connection.  
2. Bitrix24.Disk / согласованный диск, если Qlik его видит.  
3. Позже: REST/QVD из того же скрипта.

Не использовать личный GitHub как боевой источник. Корп. git — для кода скрипта, не для того, чтобы Qlik ходил в Actions.

## Практики

- Один URL правды: прод.  
- Одна схема файла, даты ISO, единицы в колонке `unit`.  
- В каждом объекте Qlik — измерение `contour`.  
- Desktop не подменяет mobile.  
- Reload по расписанию, не «открой и нажми».  
- Секреты только в `.env`, не в репозитории и не в чат модели.

- Тащить accessibility и все категории Lighthouse в карточку Жени.
