# ТЗ хостеру — B5.3–B5.5 (скорость a2c.by)

**Сайт:** https://a2c.by/  
**Платформа:** 1С-Битрикс 25 · PHP 8.3 (Beget/хостинг)  
**Дата:** 11.08.2026  
**Контакт:** маркетинг A2 Consulting  

## Контекст

По панели Perfmon Битрикс конфигурация ≈ **7.25** при эталоне ≥30. Узкие места серверной части — без PHP-ускорителя и с файловым кешем.

Контроль скорости сайта 11.08.2026 (Lighthouse mobile lab): главная **Perf 58 / LCP 4.7 с / TBT 940 мс**; TTFB HTML уже хороший (~30–140 мс за счёт композита). Серверный потолок всё равно мешает дожать Perf ≥85 и стабильный field CWV.

## Просим выполнить

### 1. Zend OPcache (обязательно)

- Включить **Zend OPcache** для PHP 8.3 сайта a2c.by  
- Типичные параметры (ориентир):
  - `opcache.enable=1`
  - `opcache.memory_consumption=128` (или выше)
  - `opcache.validate_timestamps=1`
  - `opcache.revalidate_freq=60`
- После включения: подтвердить `phpinfo()` / что модуль active

### 2. MySQL

- `transaction_isolation = READ-COMMITTED` (или `tx_isolation` на старых версиях)  
- Разобрать / снизить **Aborted connections** (если видно в мониторе)  
- Кратко описать текущие лимиты `max_connections`, `wait_timeout`

### 3. Redis для кеша Битрикс (желательно)

- Поднять **Redis** (или Memcached) на сервере  
- Сообщить: host, port, password (если есть), доступ только с localhost  
- Мы сами переключим хранилище кеша Битрикс на Redis в админке

## Как проверим

1. Битрикс → Производительность → рекомендации PHP (OPcache не красный)  
2. Повторный Perfmon → конфигурация **заметно выше 7.25**  
3. PageSpeed / Lighthouse mobile: TTFB гостя без деградации; целевой ориентир после OPcache+Redis — рост Perfmon и вклад в Perf ≥65–70 на пути к ≥85
