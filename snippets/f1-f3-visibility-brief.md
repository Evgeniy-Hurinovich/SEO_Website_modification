4. Дождаться статуса **«Обработан»** (не «В очереди»).

## F3 — цели Метрики: заявка из органики (~30 мин)

**Зачем:** KPI «видимость → лиды», а не только «позиция ~10».

**Счётчик:** https://metrika.yandex.ru/ → **108757686**

### Цели (рекомендуемый минимум)

| № | Название | Тип | Условие |
|---|----------|-----|---------|
| 1 | **Клик «Заказать звонок»** | JavaScript-событие или клик | Элемент `[data-name="callback"]` или текст ссылки «Заказать звонок» |
| 2 | **Открытие формы обратной связи** | JavaScript-событие | Клик «Получить консультацию» / открытие popup webform (Aspro `data-param-id="8"`) |
| 3 | **Отправка CRM-формы B24** | JavaScript-событие | Успешная отправка inline-формы (`data-b24-form="inline/29/cjt1zt"`) — при необходимости настроить событие в B24 → Метрика |
| 4 | **Клик по телефону** | Клик | URL содержит `tel:` |
| 5 | **Переход на /contacts/** | URL | `https://a2c.by/contacts/` |

### Сегмент «Органика»

**Отчёты → Источники → Поисковые системы** или сегмент:
- Источник = **Поисковая система**
- Метка = **organic** (или «Яндекс / Google» без рекламы)

Сохранить сегмент **«Органический трафик»** и смотреть цели 1–5 только по нему.

### Проверка после настройки

1. Открыть сайт в режиме инкognito → клик «Заказать звонок» → в Метрике **«Онлайн»** должна мигнуть цель (лаг 1–5 мин).  
2. Через 24 ч: **Отчёты → Конверсии → Цели** с сегментом organic.
