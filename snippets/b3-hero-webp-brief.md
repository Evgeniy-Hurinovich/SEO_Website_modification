## Как сжать (Squoosh)

1. Откройте https://squoosh.app/  
2. Загрузите исходный JPG.  
3. Правая панель: **WebP**, качество ~70–80.  
4. Ширина: обычно **1920px** достаточно (не больше исходника).  
5. Скачайте, если вес **>120 KB** — снизьте качество до 60–70.  
6. Имя файла: понятное, латиницей, например `hero-dwh-it.webp`.

Альтернатива: Photoshop / TinyPNG / ImageMagick.

## Как заменить в Битриксе

1. Откройте список IB 23 (ссылка выше).  
2. Найдите элемент по заголовку слайда → **Изменить**.  
3. Вкладка с картинкой / **Детальная картинка** / свойство фона баннера (то поле, где сейчас JPG).  
4. Удалите старый файл → загрузите новый **.webp** из папки `snippets/b3-hero-webp/`.  
5. **Сохранить**.  
6. Повторите для 4 слайдов.  
7. Кеш: https://a2c.by/bitrix/admin/cache.php?lang=ru → очистить.  
8. Если включён Композит — сбросить композитный кеш тоже.

## Проверка

1. Главная https://a2c.by/ → view-source / DevTools Network: фоны слайдов — **webp**, вес ≤120 KB.
